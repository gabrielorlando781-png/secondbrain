# Crônica de Criação: O Legado de Gabriel & Antigravity

Este documento serve como a memória mestre de todos os sistemas inteligentes e experimentos desenvolvidos nesta parceria. É o ponto de convergência entre visão computacional, IA e interfaces futuristas.

## 🛰️ Projetos em Órbita

### 1. Sentinela — Detector de Sonolência
*   **Foco:** Segurança e Visão Computacional.
*   **Diferencial:** Uso de Face Mesh para monitorar a fadiga em tempo real.
*   **Status:** Fase de integração de alarmes.

### 2. JARVIS — Assistente de Voz
*   **Foco:** Interação Humano-Computador Natural.
*   **Diferencial:** Integração direta com a API do Gemini para conversas contextuais e controle de sistema por voz.
*   **Status:** Operacional.

### 3. HandLines & Spatial Builder
*   **Foco:** Interfaces Espaciais e Gestos.
*   **Diferencial:** Transformação de gestos manuais em desenhos 2D e construções 3D (Three.js).
*   **Status:** Protótipos avançados.

### 4. Second Brain (O Hub)
*   **Foco:** Gestão de Conhecimento e Persistência.
*   **Diferencial:** Conectado universalmente à IA para gerar memórias automáticas. Publicado via Vercel/GitHub.
*   **Status:** **ATIVO & UNIVERSAL**.

## 🛠️ O Ecossistema Técnico
Nossas criações seguem um padrão de excelência:
*   **Design:** Estética Dark, Glassmorphism, Neon Accents.
*   **Performance:** Código otimizado para rodar no navegador com baixa latência.
*   **Modularidade:** Tudo o que aprendemos em um projeto (ex: MediaPipe) é reaproveitado no próximo.
